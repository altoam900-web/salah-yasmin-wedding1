# دعوة زفاف صلاح & ياسمين — النسخة النهائية

هذه النسخة جاهزة للنشر على GitHub Pages.

## مهم جدًا
ارفع **كل محتويات هذا المجلد** إلى جذر الـ Repository، بحيث يكون الشكل:

```text
index.html
style.css
script.js
assets/
  gallery-01.jpg
  gallery-02.jpg
  gallery-03.jpg
  gallery-04.jpg
  wedding-song.mp3
```

لا تضع الملفات داخل مجلد إضافي بعد فك الضغط.

## الصور والموسيقى
الصور والأغنية موجودة داخل `assets/` بالفعل، والمسارات في الصفحة هي:

- `assets/gallery-01.jpg`
- `assets/gallery-02.jpg`
- `assets/gallery-03.jpg`
- `assets/gallery-04.jpg`
- `assets/wedding-song.mp3`

الموسيقى تبدأ عند الضغط على «افتح الدعوة» لأن المتصفحات الحديثة تمنع التشغيل التلقائي بدون تفاعل من الزائر.

## GitHub Pages
من إعدادات المستودع:
1. Settings
2. Pages
3. Deploy from a branch
4. Branch: `main`
5. Folder: `/ (root)`
6. Save

بعدها سيظهر رابط الموقع من GitHub Pages.
